# Milestone 0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deterministic, snapshot-able `Return.Sim` that runs the first-camp cast for a year on a tile grid and produces stories a stranger can retell, plus a headless runner/soak and a rectangles-and-text Godot view.

**Architecture:** `Return.Sim` is a pure net8.0 library: plain state classes (lists ordered by id, integer values), static systems called in a fixed order each tick, an event log with causes and effects, JSON snapshots. Tools and the Godot project consume it only through `Simulation`, `StateApi`, `EventText` and commands.

**Tech Stack:** .NET 8 (SDK 8.0.408), C# 12, System.Text.Json, xUnit 2.9.3, JsonSchema.Net (tests), Godot 4.7.2 .NET (`Godot.NET.Sdk/4.7.2`), GitHub Actions.

**Spec:** `CLAUDE.md` (source of truth), `BIBLE.md` §4 (M0 simulation), `DECISIONS.md` ADR-0002…0008 and ADR-0011. Reference for ported behaviour: `archive/return-demo/dist/sim.js`.

**Execution shape (founder asked for simple orchestration):** Tasks 1–6 and 9–13 inline, in order. After Task 6 a small background workflow runs Task 7 (runner) and Task 8 (Godot view) in two worktrees; they touch only `tools/` and `game/`. Before Task 14, one adversarial review workflow (determinism, Godot leakage, story counting).

## Global Constraints

- Godot 4.7.2, `Godot.NET.Sdk/4.7.2`; every C# project targets `net8.0`.
- `Return.Sim` has zero Godot references and no NuGet packages. Allowed packages: xUnit 2.9.3, xunit.runner.visualstudio, Microsoft.NET.Test.Sdk, JsonSchema.Net (tests only); Godot.NET.Sdk 4.7.2 (game only). Anything else needs founder approval.
- "Deterministic: fixed tick; two RNG streams, `Truths` and `Dice`; every random draw names its stream; same seed and inputs produce an identical world. A test enforces this."
- In the sim: no `System.Random`, no `DateTime`/`Stopwatch`, no floating point in state or decisions, no iteration over `Dictionary`/`HashSet` that affects state, no `string.GetHashCode()`. Invariant culture for all formatting.
- "Snapshot and restore of full world state (including character memories) at fate knots; restore under 1 s at 200 characters."
- "Data-driven: species, traits, needs, incidents, ideas and items live in `/content/*.json` with schemas. No content in code." Changing a schema after Task 3 needs founder approval.
- "Mod hooks and localization keys for every player-facing string from day one." No English composed in C#.
- Story = "a chain of 3 or more causally linked events across 2 or more systems, involving a named character, ending in a persistent state change."
- Calendar: 300 ticks/hour, 24 h/day, 10 days/season, 4 seasons/year (288,000 ticks/year); daylight 06:00–19:00. Map 48 × 32.
- M0 view: coloured rectangles and text; map fills the window; one bottom menu bar; inspector only on click (ADR-0008). Never direct unit control.

## Review Focus

1. A full in-game year for any seed must finish without exceptions and keep invariants: needs, health and mood in range; no negative item counts; nobody standing on an impassable tile; every cause id names an earlier event. (Test: Task 13 Step 6, `YearInvariantTests`.)
2. A snapshot taken mid-activity (someone mid-path, a job half done, rain falling, a thief on the map) must restore to an identical future. (Test: Task 13 Step 7, snapshot every 1,777 ticks for three days.)
3. A content mistake (a cast entry naming a trait that does not exist) must fail at load with a message naming the file and the id, not crash at tick 50,000. (Test: Task 3 Step 1, `BadTraitIdNamesFileAndId`.)
4. An empty camp (everyone dead or gone) must keep running, and the runner must still print a log. (Test: Task 12 Step 7, `EmptyCampKeepsRunning`.)
5. Soak results must not depend on thread count: `--parallel 8` and `--parallel 1` write byte-identical per-world logs. (Test: Task 7 Step 4, `SoakIsThreadCountIndependent`.)
